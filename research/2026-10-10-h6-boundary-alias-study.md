# H6 — 境界位置・ローマ字表記揺れの検証

**検証日：2026-10-10（JST）**。H5の独立Python候補生成器を基準に、ローマ字入力方式と日本語・英語の切替境界を同時評価した。**C# StreamHybrid/Windows IMEには未統合。**

## 研究仮説と測定範囲

H6：「日本語ローマ字の入力方式差を同じ音韻として扱い、候補の前後が日本語として区切れるかを加点すれば、H5の最上位候補の境界精度が改善する」。

H5では候補中に正しい英語範囲が含まれるかを中心に測っていた。今回はそれに加えて次を分離して測定する。

- **候補集合のGold包含（Top4候補再現）**：正しい英語区間が候補に残っているか
- **Rank1完全一致**：最優先候補の開始・終了両方が正確か
- **言語切替境界Precision/Recall/F1**：最優先英語候補の開始・終了境界と正解の一致。日本語のみ負例に誤英語候補を出した場合はFPとして加算
- **±1文字両端一致**：最優先候補の開始・終了双方が正解から1文字以内
- **開始・終了位置MAE**：候補が選択されたケースに限定した絶対誤差。候補が無いケースは除外しているため単独評価不可
- **ローマ字表記ペア双方の完全一致**：読みが同じ2種類の打鍵方法で、両方正しい境界を選べた語数（54組）

ここでの**境界F1は日本語⇔英語の言語切替だけ**であり、助詞を含む日本語内部のすべての語彙境界ではない。後者は人手正解の語分割を収集するまで「未評価」とする。

## 具体的な方式

C#の `src/BoundaryLab.Core/RomajiConverter.cs` からトークン対応表を読み込み、以下の対を実際に同じかなに変換できることを確認した。

| 2種類の入力 | C#表での同値 |
|---|---|
| `shi / si` | し |
| `chi / ti` | ち |
| `tsu / tu` | つ |
| `fu / hu` | ふ |
| `sha / sya` | しゃ |
| `sho / syo` | しょ |
| `cha / tya` | ちゃ |

評価では同じ未知英単語を、たとえば `shigotodecustomer**ni**shimasu` と `sigotodecustomer**ni**simasu` の2表記で比較。**Gold境界は生入力文字列の長さから自動計算**し、短い表記に変わった分だけ開始・終了オフセットも変える。英語側を `shi→si` のように正規化する処理は行わない（英語の綴り、識別子、URLを破壊するため）。

H6では既存H5の文字モデル＋音韻＋前後文脈スコアに、**前後が完全に日本語ローマ字で解釈できるか**と**境界を1字英語側に動かすと日本語として読みにくくなるか**という切断信号を追加する。学習済みデータやGold境界を特徴量として与えず、加算重み0.9は先に固定。閾値は以前と同じ日本語開発165合成例の5%経験的誤候補予算で校正し、最上位4候補を出す。

英語評価54語を6組の別表記コンテキストに割り振り、各語につき2入力：**正例108件**。日本語のみ34語種の2入力で**負例68件**。この評価を5種類の学習分割で繰り返す。異なるSeedも同じ54英語語種を再使用するため、540件の独立な未知語を評価したことにはならない。

## 失敗例とローマ字対応の追加課題

- `chikakudebasicallynitsukau`：Gold開始9に対しRank1開始11。英単語の先頭2文字を日本語側に誤吸収する。
- `chousanodeadlinenifutari`：Gold開始8に対しRank1開始7。境界を1字早く選ぶ。
- `chikakudeupdatenitsukau`：候補生成・閾値選択によりRank1に英語候補がなくなる。
- 一般的な `ji` は現行C#のローマ字表に**存在しない**（`zi` は「じ」に対応）。表記揺れ全般を扱えるわけではない。
- `n`と`nn`の差、促音、長音、末尾未確定、英語固有名詞、記号、大小文字、ユーザー辞書の意図情報は別途テストが必要。

特に日本語入力のローマ字表現を**全文一括で同じ綴りへ書き換えてはならない**。`shi`と`si`を同一音として扱うのは、日本語と判定された範囲の音韻候補内に限るべきで、元入力座標と英語の原文を必ず保持する。

## 次の研究：H7の方向性

1. **二階層の正解境界**：言語切替境界（日本語/英語/コード）と日本語の語彙境界（単語・助詞）を別々のGoldとして作り、micro F1・exact span・MAE・表記揺れペアの両方を測定する。
2. **広いローマ字別表記**：`ji/zi`、`n/nn`、撥音・促音・長音・拗音などで部分入力の可逆な対応を追加し、英単語の表記を変更しないテストを作る。
3. **悪化を防ぐ選択制御**：候補がない場合の保留処理、±1文字以内の悪化、誤英語候補を同時制約し、H6方式をそのまま組み込まず候補集合の段階診断を先に行う。
